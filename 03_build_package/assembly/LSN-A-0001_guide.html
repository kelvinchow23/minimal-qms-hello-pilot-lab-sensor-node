Before you start

Tools
  • Heat-set insert tool with an M2 tip (about 230 °C for PETG)
  • Phillips #0 precision screwdriver
  • Computer with Raspberry Pi Imager and a microSD card reader
Consumables
  • Serial number label
Safety
  • The insert tool is hot: let the base cool before handling it.
  • Handle boards by their edges.

Flash B2 before you start: software/lsn-node/README.md, steps 1 to 3. Hostname = the unit's serial number. No Wi-Fi password or server address goes into any file in the repo (REQ-010).

W · Wires: build these first

No wires to build for LSN-A-0001: W1 is bought ready-made (both ends fitted). Check both plugs are seated in their housings.
