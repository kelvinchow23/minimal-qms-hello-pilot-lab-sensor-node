# TP-001 Readings, rate, reporting and timestamps

Run on each unit (every requirement applies to each unit).

## Setup
- Unit assembled and installed per `software/lsn-node/README.md`, lid on, on a bench.
- EQ-001 test receiver running (`tools/receiver.py`) on an NTP-synced computer; the unit's
  `server_url` points to it. Unit powered for at least 5 min before starting.

## Steps
- **Step 1:** Let the unit run for 15 min. Run `python tools/check_run.py readings.jsonl <unit>`.
- **Step 2:** Missing fields. Limit: none missing (temperature, humidity, pressure, VOC index
  all present, each with its unit in the field name). Checks REQ-001, REQ-004.
- **Step 3:** Largest gap between readings. Limit: 10 s or less. Checks REQ-002.
- **Step 4:** Readings arrive at the receiver over the lab Wi-Fi. Limit: at least 85 readings in
  the 15 min. Checks REQ-004.
- **Step 5:** Largest |unit time - receive time|, and unsynced readings. Limit: 1 s or less, and
  0 unsynced readings. The offset includes network delay, so a pass is conservative.
  Checks REQ-011.

## Pass criteria
All steps within limits. Record the `check_run.py` output in `test_results.csv`.
