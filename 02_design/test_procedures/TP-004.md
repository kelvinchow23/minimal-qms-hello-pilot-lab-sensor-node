# TP-004 72 h unattended run

## Setup
Both units running as in TP-001, lid on, on a bench in the lab. Nobody touches them during the run.
The receiver computer must stay on and connected for the whole run.

## Steps
- **Step 1:** Run for 72 h. Then run `python tools/check_run.py readings.jsonl`.
- **Step 2:** Gaps. Limit: no gap over 10 s. Checks REQ-012.
  A gap caused by a network or receiver outage (check the receiver computer's and network's
  logs) is not a unit failure: record it, and either repeat the run or disposition it (SOP-008).
- **Step 3:** Record the maximum CPU temperature. No limit; it checks the heat estimate behind
  RISK-001 (Pi bay vents).

## Pass criteria
Step 2 within limits on each unit.
