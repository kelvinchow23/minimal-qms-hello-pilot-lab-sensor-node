# TP-003 Unattended restart

## Setup
Unit running as in TP-001, with the overlay file system enabled (README step 8).

## Steps
- **Step 1 (power cuts, 3 times):** Unplug the wall supply for 10 s, plug it back in, and do not
  touch the unit. Note the time power was restored.
  Limit: readings resume at the receiver within 2 min, each time. Checks REQ-009.
- **Step 2 (Wi-Fi drops, 3 times):** Drop the unit's Wi-Fi for 60 s without touching the unit,
  e.g. switch off the access point it uses, or run over SSH:
  `sudo sh -c 'ip link set wlan0 down; sleep 60; ip link set wlan0 up'`.
  Limit: readings resume within 2 min of Wi-Fi returning, each time. Checks REQ-009.

## Pass criteria
All 6 events within limits. Readings missed during the outages are expected (recovering them is
out of scope).
